The web app will contain these pages:

# Signup page
- allows new users to create an account

# Login page
- allows registered users to log in
- find my account / reset my passwords

# User profile
- user can edit their account name, passwords, favourites list and customised movie lists etc.

# Home/browse page
- displays all movies fetched from TMDB in card style

# Individual Movie Page (Description & Reviews)
- Display the movie title
- Display the movie description (e.g., storyline, genre)
- Display the average rating
- Display user reviews

# Write review page
- a form for registered users to write reviews and pick the star rating(0-5)
